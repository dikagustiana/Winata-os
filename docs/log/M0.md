## Bukti RLS di PGlite

Probe sebelum tabel proyek dibuat (`scripts/probe-rls.ts`, sudah dihapus setelah
bukti dicatat):

```
before [ { current_user: 'postgres',
           claims: '{"sub":"1111...","role":"authenticated"}' } ]
after  [ { current_user: 'authenticated',
           uid: '11111111-1111-1111-1111-111111111111', visible: 1 } ]
ERROR read other row: 0 rows (RLS menyaring; bukan galat SQL)
visible rows [ { id: 1, owner: '1111...', label: 'a' } ]
```

Kesimpulan: `set role authenticated` + `set_config('request.jwt.claims')` + policy
`auth.uid()` bekerja di PGlite 0.3.16. Tidak ada RLS yang dimatikan.
