# Log M8 — Worker cloud (v1.1, menutup Q-11 / F-7)

## Rencana

1. `packages/db/src/queryable.ts`; tipe `PGlite` → `Queryable` di `rebuild.ts`, `controls.ts`, `outlook-worker.ts`.
2. `packages/db/src/pg-cloud.ts` (`createCloudDb`, Pool max 1, parser tipe) + tes tanpa koneksi (merah dulu).

6. Bukti jalur `pg` nyata terhadap PostgreSQL sungguhan; gerbang typecheck/test/lint/e2e.

## Yang dibuat

- `packages/db/src/queryable.ts` — `Queryable { query<T>(sql, params) → { rows } }`. PGlite
  memenuhinya tanpa adapter; tes worker v1 (rebuild 7, kontrol 3) tidak diubah dan tetap hijau.
- `packages/db/src/pg-cloud.ts` — `createCloudDb(url)`: `pg.Pool` `max: 1`,
  `idleTimeoutMillis 10_000`, `connectionTimeoutMillis 10_000`, `ssl.rejectUnauthorized=false`
  hanya untuk host `*.supabase.com/.co` (sslmode dilepas dari URL agar opsi eksplisit berlaku);
  parser per pool: `date`→`YYYY-MM-DD`, `timestamp/timestamptz`→ISO, `numeric`→string, `int8`→number bila aman,
  `json/jsonb` bawaan. Diekspor lewat subpath `@winata/db/cloud` agar `pg` tidak ikut ke modul lain.
- `processRebuildQueue` memakai `claim_rebuild … generation` dan `mark_rebuild_done(location, generation)` (R-65).
- `apps/web/lib/cloud-db.ts` — `getWorkerDb()`: PGlite bila mock, selain itu singleton `createCloudDb(SUPABASE_DB_URL)` di `globalThis`.
- `apps/web/lib/cron.ts` + `api/cron/rebuild` + `api/cron/controls`: 401 tanpa bearer, 503 bila
  `SUPABASE_DB_URL` kosong, 500 JSON bila worker galat; `runtime nodejs`, `maxDuration 300`,
  rebuild ≤ 10 lokasi per invokasi, bootstrap `?full=1&from=YYYY-MM-DD` (semua lokasi dari tanggal itu).
- `lib/actions/common.ts#rebuildLocal`: worker inline lewat `getWorkerDb()`; di cloud hanya bila
  tanggal ≤ 7 hari ke belakang (sisanya antrean + cron), di lokal selalu inline (tanpa cron);
  galat dicatat, aksi tetap sukses. `physical.ts` (kontrol) dan `recon.ts` (sesudah impor:
  `processRebuildQueue` + proyeksi + kontrol) memakai jalur yang sama.
- Dependensi baru: `pg` (`@winata/db`, `@winata/web`) dan `@types/pg` (dev). Alasan: K17 — worker
  cloud menjalankan kode worker yang sama lewat koneksi Postgres langsung. `pg` juga dimasukkan ke
  `serverExternalPackages` Next. Tidak ada dependensi lain.
- `.env.example`: `SUPABASE_DB_URL`, `MOCK_AUTH_ALLOW_PRODUCTION_BUILD`. `scripts/e2e-server.mjs` dan
  `.github/workflows/ci.yml`: `MOCK_AUTH_ALLOW_PRODUCTION_BUILD=1`.
- `playwright.config.ts`: `launchOptions.executablePath` dari env `PW_CHROMIUM_PATH` bila diisi
  (lingkungan tanpa unduhan browser); CI tidak mengisinya.
- `vitest.config.ts`: alias subpath (`@winata/db/local`, `@winata/db/cloud`) diletakkan sebelum
  `@winata/db` (alias dicocokkan sebagai prefiks berurutan).
