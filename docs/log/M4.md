# Log M4 — Kas 13 minggu dan afkir indikatif

## Rencana

1. Engine `cash13.ts` (R-36) memakai `collection_profile` dari parameter, bukan hardcode.
2. Engine `cull.ts` (R-37) dengan parameter pakan/afkir.
3. Fixture `cash-example` (pendapatan 3 minggu × 3 jenis pelanggan, rencana kas 13 minggu).
4. Tab Kas 13 minggu dan Afkir di `/outlook`; input saldo/kas di `/rekon`.
5. Migrasi `0006_cash.sql` (index + check nominal).
6. Tes T-40…T-43.

## Yang dibuat

- `packages/engine/src/cash13.ts` — profil penagihan (fraksi atau persen),
  penagihan per minggu, saldo berjalan, saldo terendah.
- `packages/engine/src/cull.ts` — margin harian, ambang afkir, saran lanjut/tinjau.
- Fixture `fixtures/cash-example/{input,golden}.json` (dihitung `scripts/make-fixtures.ts`).
- Tab Kas dan Afkir di `/outlook`; form saldo awal dan rencana kas di `/rekon?tab=kas`.
- `0006_cash.sql`.

## Fixture dan golden

- 13 minggu, saldo awal Rp 250.000.000, penagihan bakul/agen/grup.
- Saldo terendah **−Rp 101.000.000 pada minggu 18 Jan 2027** (golden dari skrip terpisah).
- Profil: bakul [1], agen [0,5; 0,5], grup [0, 0, 1], lain [1].
